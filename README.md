# 🛡️ Network Intrusion Detection System

A production-oriented Machine Learning project for detecting malicious network traffic using modern classification algorithms.

## Objectives

- Detect malicious network connections
- Compare multiple machine learning models
- Explain predictions using SHAP
- Build a FastAPI backend
- Develop an interactive dashboard
- Deploy using Docker

## Tech Stack

- Python 3.11
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- FastAPI
- Plotly
- Jupyter
